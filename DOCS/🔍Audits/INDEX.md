# 🔍🧾🚦 Audits

> Findings against the built thing — the North Star audit corpus.

> **The Subject column is the audit's own expiry date.** Every document here declares a `subject:` list in its front matter — the repository paths it is about — and the verdict below is read off that list by `check_audit_contract.py`, not maintained by hand.
>
> `✅ live` — every path it names is still tracked. `⚠️ partial` — some of its subject has left the repository, so part of it is about a ghost. `🕯️ retired` — none of its subject remains: the audit's job has ended, and it is history rather than a finding. `— no subject` — a frame document that has declared it has none.
>
> Twenty audits were ruled MOOT in one pass on 2026-09-04 by a person reading each of them; a 953-line report about a folder that had shrunk to five files had been reading as a live finding for a week. This column is so that never has to be a reading pass again. PLAN-331.01.
